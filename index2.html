ACADEXA is a student performance tracking project designed to simplify academic result calculations through fundamental programming concepts.

About the Project

A simple academic performance tracking system developed using C++ and HTML.

Core Features

01. Student Details

Accepts student name and roll number.

02. Marks Management

Accepts marks for five different subjects.

03. Result Calculation

Calculates total marks and percentage automatically.

04. Grade Evaluation

Classifies academic performance using grade criteria.

05. Result Status

Determines whether the student has passed or failed.

06. Simple Interface

Provides a structured webpage for project information.

Technology Stack

Built using fundamental programming and web development tools.

C++ Programming
HTML5
CSS3

Grading Criteria

Academic grade classification used by the program.

Percentage Grade Status
90 – 100 A+ Pass
80 – 89.99 A Pass
70 – 79.99 B Pass
60 – 69.99 C Pass
35 – 59.99 D Pass
Below 35 in any subject F Fail

Project Objective

To apply fundamental C++ programming concepts to develop a simple student result management system while improving logical thinking, problem-solving and basic web development skills.

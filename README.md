# Student Performance Tracker

## About
A beginner-friendly project developed using C++ and HTML.

## Features
- Student information
- Marks entry
- Total marks calculation
- Percentage calculation
- Grade calculation
- Pass/Fail result

## Technologies
- C++
- HTML

## Concepts Used
- Variables
- Arrays
- Loops
- If-else statements
- Arithmetic operators
- Basic HTML elements

## How to Run
1. Open main.cpp in a C++ compiler.
2. Compile and execute the program.
3. Enter student details and marks.
4. View the calculated result.
5. Open index.html in a web browser.

## Purpose
Created to practise fundamental programming concepts.
